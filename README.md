## ✨ Features

- **Exact Age Calculation:** Accurately computes exact age breakdown in **Years**, **Months**, and **Days**.
- **Real-Time Input Validation:** Inline error checks for missing fields, invalid calendar dates (e.g., Feb 31), and future date selections.
- **Animated Counter Effect:** Smooth counting animation for displaying calculated numbers.
- **Theme Preference Persistence:** Dark & Light UI mode switch with `localStorage` state saving.
- **Responsive & Accessible Design:** Clean mobile-first design with accessible form inputs.

---

## 🛠️ Tech Stack & Concepts Applied

- **Frontend:** HTML5, Modern CSS3 (CSS Variables, Flexbox, CSS Grid)
- **Scripting:** Modern JavaScript (ES6+, DOM Manipulation, Event Listeners)
- **Data Persistence:** Browser `localStorage` API
- **Version Control:** Git & GitHub Pages for live hosting
